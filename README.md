# collatz-tree-for-uiua
Trying to find the starting number with the longest collatz sequence under 1 million in Uiua and could not make it happen without having to wait several minutes for the program to find it.
I then found and read a research paper on [unfolding the collatz tree](https://www.tandfonline.com/doi/full/10.1080/27684830.2025.2542052#abstract) and tried replicating the code in Zig to then transcribe to Uiua and see how much more efficient it will be.
